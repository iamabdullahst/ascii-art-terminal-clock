# Matrix Terminal Clock

A bright-green 24-hour digital clock over a black, Matrix-inspired falling-character background. It targets an 80×24 terminal and redraws at 30 FPS.

## Run

```bash
python3 matrix_clock.py
```

Use `q` or `Ctrl-C` to exit. The terminal must be at least 53 columns by 10 rows. A wider terminal gives the rain field more room around the clock.
